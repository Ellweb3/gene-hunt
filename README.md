# gene-hunt: малоизученные белки, по которым много экспериментальных данных

Вычисления — Rust (`src/main.rs`), загрузка — curl/Python. Сырые большие файлы (DepMap 26Q1 gene_effect.csv,
NCBI gene2pubmed.gz) не хранятся: качаются заново (см. ниже).

## Метод
1. Кандидаты — 5501 белок Tdark из Pharos (IDG) → `data/pharos_tdark.json`.
2. Слои данных: публикации (NCBI gene2pubmed), DepMap Chronos 26Q1 (figshare 31660582, `gene_effect.csv`),
   BioPlex 3.0 (293T + HCT116), HPA subcellular_location.
3. Ко-зависимость в DepMap: Пирсон по ~1100 линиям, гены с ≥ 500 линиями, исключены соседи по цитобэнду
   (артефакт числа копий) и семейства многокопийных генов (OR, KRTAP, GOLGA6/8, AGAP, POTE, SPDYE… — многократный
   разрез даёт ложную «эссенциальность»). Итог: `data/tdark_profile.tsv`.
4. Фильтр: реальная зависимость (≥ 5% линий < −0.5 или среднее ≤ −0.2), партнёр r ≥ 0.3, нет функции в UniProt
   (`data/candidates_unknown_function.json`), затем ручная проверка: отброшены субъединицы известных комплексов
   (митохондриальная рибосома, SAGA, минорный сплайсосом) и гены со свежими функциональными статьями (TTC27 — 2026,
   GPATCH1/LENG1 — 2026, KTI12, OST4, PET117, PYURF).

## Финалисты (ко-зависимость DepMap и физические взаимодействия BioPlex независимо указывают на один комплекс)
| ген | DepMap | ко-зависимость | BioPlex | литература |
|---|---|---|---|---|
| **TMCO6 + ZNF511** | ср. −0.11, 7–8% линий < −0.5, мин. −1.4 | **взаимно лучшие партнёры, r = 0.60** (следующие 0.24/0.23) | друг с другом + кольцо LSm (LSM3–7); LSM4/LSM7 как приманки вытаскивают оба | связи не описаны |
| **SS18L2** | ср. −2.59, 99% линий — общеэссенциальный | WDR82, NIP7 (слабо, 0.32) | весь BAF (SWI/SNF): SMARCA2/4, SMARCB1, ARID1A/B, SMARCC1/2, SMARCD1–3, DPF1–3, BRD9… | отмечен как субъединица SWI/SNF (2022); почему нужен почти всем линиям — неизвестно |
| **C19orf25** | ср. −0.13, 12% | BNIP1 0.52, NBAS 0.47, ZW10, STX18 | все субъединицы комплекса синтаксина-18/NRZ (BNIP1, NBAS, RINT1, ZW10, STX18, USE1, SEC22B, SCFD2) | упомянут в систематических работах (2018, 2026), отдельной статьи нет |

Рекомендация: **TMCO6–ZNF511** — самый новый сигнал (пара неизученных генов, связанная с машиной LSm, которая
участвует в сплайсинге (U6 snRNP, LSM2–8) и распаде мРНК (LSM1–7)).

## Разбор финалистов

- [TMCO6–ZNF511](TMCO6_ZNF511.md): импортиноподобный модуль при ядерном кольце LSm2–8 (U6 snRNP).

## Повторить
```
S=<временная папка>
curl -sL https://ndownloader.figshare.com/files/67214582 -o $S/gene_effect.csv
curl -s https://ftp.ncbi.nlm.nih.gov/gene/DATA/gene2pubmed.gz -o $S/gene2pubmed.gz
cargo run --release -- $S/gene_effect.csv $S/gene2pubmed.gz
```
